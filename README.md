# iNaturalist Citizen Science Data Ingestion + Bias Insights

## Getting Started
### Prerequistes
Make sure you have these installed on your machine:
 * [Python 3](https://www.python.org/downloads/)
 * [uv](https://docs.astral.sh/uv/#installation)

### Setup
1. Clone this repository using your preferred method ([see here](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)).
2. Within the repo directory, run `uv sync` to install/update/audit the required packages as necessary.
